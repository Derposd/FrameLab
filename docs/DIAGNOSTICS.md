# Диагностика FrameLab 2.0

Откройте «Диагностика» под списком профилей. Выберите инструмент и, для игровых проверок, игру. Переключатель тёмной темы расположен внизу страницы.

| Инструмент | Проверка |
|---|---|
| Game Doctor | Выберите один из семи симптомов и запустите проверку при появлении проблемы. Для вылетов читаются журналы Windows за семь дней. Для высокого пинга предлагается сетевой тест. |
| FrameLab Overlay | Выберите режим, угол основного экрана и метрики. Нажмите «Включить с этими настройками». Для FPS используйте существующую запись матча или запустите 60-секундную запись уже открытой игры. |
| Network Doctor | Отдельный запуск отправляет по 16 ICMP-проб к шлюзу и Cloudflare и проверяет DNS адаптера. Можно включить запрос списка Valve и тест первого опубликованного релея. Это ориентир для маршрута. В конкретном матче могут использоваться другие сервер и протокол. |
| Задержка ввода | Проверяет частоту дисплея, питание, фоновые программы, нагрузку, кадры и видеофайл выбранной игры. Полную физическую задержку можно измерить внешним устройством. |
| Мой компьютер | Показывает инвентарь, текущие счётчики и признаки ограничений. Текстовый экспорт содержит характеристики железа и результаты проверки. |

В режиме Advanced оверлей строит график из последних 30–480 интервалов кадра, в зависимости от выбранного окна. Один прогон PresentMon обслуживает монитор, бенчмарк и диагностику в одном экземпляре FrameLab. Windows может запросить права на запись ETW. После сворачивания главного окна оверлей можно скрыть и вернуть комбинацией Ctrl+Alt+F8…F11. Видимость поверх exclusive fullscreen и защищённых игр зависит от режима вывода. «Оценить нагрузку окна» сравнивает долю CPU процесса за пять секунд со скрытым и пять секунд с видимым окном. Для оценки изменения FPS повторите игровой бенчмарк.

CPU/GPU и память читаются через Windows. Температуры CPU/GPU доступны, если уже работает локальный WMI-провайдер LibreHardwareMonitor. Его библиотека и драйвер не входят в сборку. Подписка на новый раздел использует штатный System.Management. [Лицензия проекта LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/blob/master/LICENSE).

«н/д» означает, что источник отсутствует, не дал значения или кадры ещё не записаны. Инвентарь может использовать сохранённое сканирование. На ПК с несколькими GPU значения загрузки и памяти относятся к максимальному значению среди адаптеров. Частота относится к выборке счётчиков Windows. Гипотезу о троттлинге проверьте по пределам конкретного чипа и изменению частот под нагрузкой. Диагностика не рассчитывает причину фриза из одного показания. Проверка bufferbloat требует повторяемой нагрузки и контролируемого узла. В этой версии такого узла нет. Для Wi-Fi возвращается доступная информация netsh, без сохранения SSID в отчёт.

## Ручная проверка на Windows 10 и 11

1. В небольшом окне переключите все пять инструментов и обе темы. Выберите разные игровые профили и вернитесь в центр.
2. На работающей игре включите внешний оверлей и запись. Проверьте прохождение щелчков, горячую клавишу, четыре угла, сворачивание главного окна, режимы и изменение масштаба Windows.
3. Во время записи попробуйте начать вторую. Завершите игру, проверьте пропадание показателей, повторно откройте её и сделайте новый замер. Отдельно проверьте отказ UAC и недоступный PresentMon.
4. Проверьте машину без датчиков и машину с работающим WMI LibreHardwareMonitor. Сравните CPU/GPU температуры с источником. Проверьте отмену, закрытие окна, остановку сбора и сохранение настроек после перезапуска.
5. Проверьте сеть по Wi-Fi, по кабелю, при отключённом адаптере и блокировке ICMP. Сравните графики с числом ответов и результатом на стороне игрового клиента. Отмените тест в процессе.
6. Запустите проверку вылетов при пустом журнале и после реального сбоя. Сопоставьте события по времени с подробной страницей диагностики.
7. Проверьте экспорт отчёта: нет имени пользователя, путей, серийных номеров, SSID и IP. Сравните повторяемую сцену игры с включённым и выключенным оверлеем.

Автотесты запускаются командой из [BUILD.md](BUILD.md). Реальное поведение игры и античита требует проверки на соответствующей конфигурации.
